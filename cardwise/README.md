# CardWise 💳

A premium credit card comparison website for **Malaysia** 🇲🇾 & **Singapore** 🇸🇬

![CardWise Preview](docs/preview.png)

## Features

- **Card Comparison** - Side-by-side comparison of up to 4 cards
- **Smart Filters** - Filter by country, card type (cashback/miles), and sort by rating
- **Bank-Branded Cards** - Each card styled with the bank's signature colors
- **Detailed Reviews** - Highlights, pros/cons, signup bonuses

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Vercel** (hosting)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Sample Data

Includes 12 credit cards from major banks:
- **Malaysia**: Maybank, CIMB, Public Bank, HSBC, AmBank, RHB, Hong Leong
- **Singapore**: DBS, UOB, OCBC, Citibank, Standard Chartered
